## Sort pages by their job

{/* TODO(owner): add the reasoning behind each pairing. */}

- **Content people read** (blog, docs, portfolio): static-first, like Astro.
- **Signed-in apps with lots of state**: React or Next.js.
- **Large multilingual products** that need server rendering and SEO: Next.js — what I use at work.
- **Small tools that run in the browser**: React with Vite, or no framework at all, like utilyx.dev.
