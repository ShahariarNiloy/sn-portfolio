## Why build one

On a booking site, **bundle size is conversion**: every kilobyte the browser has to download and run delays the search box someone is waiting to use. The library we used carried a styling runtime and far more code than the platform needed.

So the goal was simple: keep everything the team relies on — the same props, hover, focus, keyboard behaviour and density — and drop everything else. Moving a screen over is mostly **an import swap**.

## Motion with manners

- **A calm motion language**: purposeful, brief, never bouncy.
- **Every component transition is 300 ms or less**, and exits are faster than entrances.
- **Reduced motion is respected everywhere**: movement becomes a fade, autoplay and shimmer stop.

## How it's measured

Each component is bundled on its own — minified, tree-shaken and compressed — and compared with its closest equivalent in the previous library, measured the same way. Framework code is left out, since the app ships it either way.
