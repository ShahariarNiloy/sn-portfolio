## Stack

Next.js, React, TypeScript, tRPC, TanStack Query, Zustand and Tailwind CSS, on AWS behind a CDN.

## What I worked on

- **Memory and stability.** A prioritized audit of JavaScript heap out-of-memory crashes, ranked by impact, with a memory-aware health check shipped. [Read more](/highlights/taming-memory)
- **Performance.** Lighthouse audits, lower Total Blocking Time and better Core Web Vitals. [Read more](/highlights/performance)
- **SEO across 26 languages.** Sitemaps, hreflang and structured data. [Read more](/highlights/seo)
- **Search.** A shared search module with per-product adapters: infinite scroll, list virtualization, map markers and batched mobile filters.
- **One property module.** Merged separate hotel and vacation-rental code paths into a single property module.
- **Flights.** URL architecture for one-way and round-trip routes, and constant-time filter indexing on results.
- **A design system of my own.** Built the platform's design system from scratch, replacing a heavy component library with about half the JavaScript. Now the standard for all new UI. [Read more](/highlights/design-system)
- **A type-safe backend-for-frontend layer** with tRPC, React Query and Zustand.
- **Tests that hold.** 80%+ coverage with Vitest and React Testing Library.
